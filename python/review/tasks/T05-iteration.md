# T05：迭代器与生成器

目标：理解按需计算和迭代器的一次性消耗。预计 20～30 分钟。

## 闭卷问题

1. 列表、`iter(列表)`、生成器分别是什么对象？
2. 同一个 map 对象连续两次 `list()`，第二次得到什么？
3. `yield` 和 `return` 有什么区别？

## 练习

建议产物：`python/practice/T05-iteration.py`。

实现生成器函数 `even_squares(limit)`，按升序生成 `0 <= x < limit` 中偶数的平方，不先创建完整结果列表。`limit=7` 应得 `[0, 4, 16, 36]`；`limit=0` 或负数结果为空。

用 next 取首项，再遍历剩余部分，最后验证该生成器耗尽。另用 product 生成长度 3 的布尔组合，验证共有 8 种。

## 验收

- [ ] 说明需要重新调用生成器函数才能获得新的遍历。
- [ ] 知道 product 的结果是迭代器，且输入池会被保存。
