# T03：列表、元组与字典

目标：能根据需求选择容器，区分复制与引用。预计 25～35 分钟。

参考：[容器](../../notes/02-basics.md)。前置条件：Python 3，能运行简单函数。

## 闭卷问题

1. `(1)` 与 `(1,)` 的区别是什么？含列表的元组能作为字典键吗？
2. `d[key]`、`d.get(key)` 缺键时各会怎样？
3. `b = a` 和 `b = a.copy()` 有何差异？

## 练习

建议产物：`python/practice/T03-containers.py`。

实现 `summarize(names)`，返回 `(首次出现顺序的姓名列表, 姓名频次字典)`，不修改输入。

输入 `["Bob", "Alice", "Bob", "Eve", "Alice"]`，预期 `(["Bob", "Alice", "Eve"], {"Bob": 2, "Alice": 2, "Eve": 1})`。再测空列表、只有重复名字、只有唯一名字。另用两层列表说明浅复制为何仍共享内层对象。

## 验收

- [ ] 输出保留首次出现顺序，不依赖 set 的顺序。
- [ ] 空输入返回 `([], {})`，原输入保持不变。
- [ ] 能用正确的两种语法创建相同字典。
- [ ] 能解释可哈希条件和浅复制的边界。
