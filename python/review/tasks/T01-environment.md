# T01：环境与解释器

目标：能判断程序究竟由哪个 Python 运行。预计 15～25 分钟。

参考：[环境管理](../../notes/01-environment.md)。前置条件：已安装 Conda；未安装时先做命令说明题，运行验收记为待完成。

## 闭卷问题

1. 写出创建、激活、列出和导出环境的命令。
2. 为什么使用 `python -m pip`？如何确认解释器路径？
3. `conda create` 和 `conda env create -f` 分别接收什么输入？

## 练习
