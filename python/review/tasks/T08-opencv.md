# T08：OpenCV 图像处理

目标：能解释数组属性，并运行一次完整处理流程。预计 30～40 分钟。

参考：[OpenCV](../../notes/05-opencv.md)。前置条件：Python 3、opencv-python（含 NumPy 依赖）。缺依赖时可先做闭卷题，运行验收留待安装后完成。

## 闭卷问题

1. 一张 shape 为 `(100, 200, 3)` 的 uint8 图像，像素数、size、nbytes 各是多少？
2. `[255, 0, 0]` 在默认 BGR 中是什么颜色？访问坐标 x=10、y=20 怎么写？
3. imread 失败返回什么？waitKey 的正确大小写是什么？

## 练习

建议产物：`python/practice/T08-opencv.py`。

用 `np.zeros((100, 200, 3), dtype=np.uint8)` 生成图像，设置 `img[:, :100] = (255, 0, 0)`，在独立临时目录保存 `input.png`。用 imread 读回，输出四个数组属性，转灰度、高斯模糊，保存两份结果；检查保存返回值。无需打开窗口即可验收。

另读一个不存在的文件，捕获读取失败并给出明确错误。可选：在有图形桌面时练习 imshow、waitKey、destroyAllWindows。

## 验收

- [ ] 像素数为 20000，size 和 nbytes 均为 60000，能解释后两者恰好相等的原因。
- [ ] 灰度 shape 为 `(100, 200)`，模糊后 shape 为 `(100, 200, 3)`。
- [ ] 能说明左半图为蓝色、右半图为黑色。
- [ ] 图像读写均检查失败分支；不在 None 上调用 cvtColor。
- [ ] 所有结果都在临时目录或自己的练习目录中，不覆盖源图。
