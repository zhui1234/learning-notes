# T02：输入、循环与切片

目标：能预测代码输出并处理循环边界。预计 20～30 分钟。

参考：[基础语法](../../notes/02-basics.md)。前置条件：Python 3。

## 闭卷问题

1. `input()` 返回什么类型？`print` 的 sep、end 怎么传？
2. 写出 `"Hello World"[-1]`、`[::2]`、`[::-1]` 的结果。
3. 循环 else 在零次迭代和遇到 break 时是否执行？

## 练习

建议产物：`python/practice/T02-basics.py`。

读取一行空格分隔的整数，输出总和、逆序列表，以及第一个负数的索引；没有负数时输出“无负数”。查找部分使用 `for ... else`。格式固定为 `sum=值`、`reversed=列表`、`first_negative=索引或无负数` 三行。

样例 `1 2 -3 4`：总和 4，逆序 `[4, -3, 2, 1]`，首个负数索引 2。边界：空行、只有 `0`、`-1 -2`、全正数。

## 验收

- [ ] 空行总和 0、逆序为空列表，且不会访问越界。
- [ ] 索引从 0 开始；找到首个负数后退出查找。
- [ ] 全正数和空输入都触发“无负数”分支。
- [ ] 能脱离运行结果解释闭卷题中的所有输出。
