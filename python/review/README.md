## 领取与验收

能独立完成就直接挑战；需要查阅时按任务中的笔记链接补缺。建议先处理 T02～T04 的基础，再选择其他主题；各任务都写有独立输入，不要求使用上一任务的产物。

1. 先不看笔记回答闭卷问题。
2. 在本任务“建议产物”路径编写解答，执行给定样例和边界输入。
3. 每条验收都通过后，在本页勾选，并在任务文件中填写记录。
4. 若查了答案才完成，记录薄弱点，稍后用不同输入闭卷重做。可在首次通过后约 3～7 天自主安排一次重测，不设固定日期。

练习解答统一放在 `python/practice/`（由完成任务时创建）。[自测要点](answer-checks.md) 提供判断线索，先做题再查看。
