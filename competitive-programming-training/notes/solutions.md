## school_2026_round3_E

26.11.4

### 0. 题目大意

- 汉诺塔问题，按最少步骤移动，移动过程中每一步移动的盘子编号形成固定序列。给出k和x，求编号为k的盘子在第x次被移动后所有没有被移动的盘子编号之积

### 1. 我的思考过程

- 思路：
寻找汉诺塔规律，尝试把k,x对应到序列中的指定位置,相同的k的间隔一定,但是从该位置找到最近的未移动盘需要的计算会超过i64上限,不知道怎么化简;
还想到把除了1以外的k等效对应到下一个1;
后来发现列一张表格更直观;

- 为什么失败或卡住：
推规律部分太容易卡住,对字母不敏感,需要列出具体的数字;
(a + b ) % mod = ((a % mod) * (b ^ -1 % mod)) % mod;
需要把1<<32写成(long long)1<<32;
mod小于int范围,变量可以用int,但是运算中要转为long long

### 2. 关键突破口

这道题最重要的性质是什么？
可以将n阶汉诺塔的第x次操作转换为n位二进制数，加入第x次操作中第k位由零变成1，则该次操作移动的是第k号盘子
所以第k号盘子第一次被移动的操作次数是2^(k-1)

### 3. 正确解法

- 核心思路：
当k号盘子被移动x次时，前n-k位二进制数对应的十进制数位x-1
只需要找到二进制最高位就知道被移动过的最大盘子

### 4. 错误与反思

- 本次最大的思维盲点：
- 容易忽略的边界情况：
- 可以迁移到其他题目的经验：
快速幂求逆元:当m为质数且(a,m)=1时,由费马小定理(a^(m-1) ≡ 1 (mod m)),得到a^(-1) ≡ a^(m-2) (mod m),可用快速幂求a^(m-2);

## school_2026_round3_A

26.11.4

### 0. 题目大意

- 一个点初始在(0,0)，进行n次运动，每次运动可以向[0,2Π)的任意方向移动1单位长度，求第n次后位移的平方的期望

### 1. 我的思考过程

- 思路：
画圈圈,但是没有列式计算

- 为什么失败或卡住：
不理解期望的计算

### 2. 关键突破口

期望的计算

### 3. 正确解法

- 核心思路：
设第i次位移大小为Li,第i+1次转动θ,则L(i+1)^2 = Li^2 + 1 - 2*Li*cosθ,
E(L(i+1)^2) = E(Li^2) + 1 - 2 * E(Li*cosθ) = E(Li^2) + 1 - 2 * E(Li) * E(cosθ),
E(cosθ)=0,
E(L(i+1)^2) = E(Li^2) + 1

## codeforces_1129_Div2_D1

26.11.4

### 0. 题目大意

- 有一个初值为零的x，在一次操作中，你可以对它做一种修改：(修改1)x+2^k，k表示此操作前连续的修改1次数；(修改2)x-1。定义f(n)为x变成n的最小操作数。求Σf(n),n∈[l,r]

### 1. 我的思考过程

- 思路：
尝试列式计算f(n),计算式可以看作若干个(2^k-1)-1组合,单次代价为k+1,贪心考虑k应该尽量大

- 为什么失败或卡住：
想到可以连续-1,不一定是单纯组合

### 2. 关键突破口

贪心+递归

### 3. 正确解法

- 核心思路：
考虑2^k <= n < 2^(k+1),
f(n) = min(k+1+f(n-2^k+2),k+1+2^(k+1)-1-n)

### 4. 错误与反思

- 可以迁移到其他题目的经验：
快速计算logn向下取整
```C++
int Log(i64 x)
{
    int res=0;
    for(int i=5;i>=0;i--)
        if(x>=(1LL<<(1<<i)))
        {
            x>>=(1<<i);
            res+=(1<<i);
        }
    return res;
}
```

## school_2026_roud4_C

26.11.4

### 0. 题目大意

- 已知非负整数a,b满足a+b+ab=x，x已知，求ab最大值

### 1. 我的思考过程

- 思路：
想把a+b通过a+b>=2根号ab换成ab直接通过浮点计算和取整计算ab的最大值

- 为什么失败或卡住：
不等式计算的是实数意义下的最大值上界，不是整数a,b下的最大值

### 2. 关键突破口

数学

### 3. 正确解法

- 核心思路：
将a+b+ab=x变形为(a+1)(b+1)=x+1
令u=a+1，v=b+1，则有uv=x+1
ab=（u-1）（v-1）=x+2-（u+v）
因为u，v为整数且整除x+1，从根号x+1开始枚举招到使u+v最小的组合

### 4. 错误与反思

- 可以迁移到其他题目的经验：
整数运算不能照搬基本不等式

## school_2026_roud4_F

2026.11.4

### 0. 题目大意

- 给出一个整数序列，可以对其中任意数s做以下任意次操作：将s变为s*2；将s变为s*4+1；将s变为s*4+3，求操作后最少有多少数不同

### 1. 我的思考过程

- 思路：
1. 把*2、*4+1、*4+3看作二进制下的末尾加0、加01和加11，把两个数能相同转为一个数是另一个数的前缀；
2. 先对整体去重，把大数不断右移，并用lowerbound查找看有没有匹配的数

- 为什么失败或卡住：
1. n^2次判断不现实；
2. 对变化条件的理解有误，误以为0、01、和11可以组合出所有可能，但实际上对于111和11并不能通过变换变成相同的数

### 2. 关键突破口

二进制

### 3. 正确解法

- 核心思路：
排序去重，从大到小枚举，将数字不断右移--末尾为0右移1位，为1右移2位，判断小的数中有没有匹配，若匹配就标记为1

### 4. 错误与反思

- 可以迁移到其他题目的经验：
从n^2的匹配到nlogn的优化
