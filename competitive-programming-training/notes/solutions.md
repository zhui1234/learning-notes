## codeforces_1129_Div2_D1

### 1. 我的思考过程

- 思路：
尝试列式计算f(n),计算式可以看作若干个(2^k-1)-1组合,单次代价为k+1,贪心考虑k应该尽量大

- 为什么失败或卡住：
想到可以连续-1,不一定是单纯组合

### 2. 关键突破口

贪心+递归

### 3. 正确解法

- 核心思路：
考虑2^k <= n < 2^(k+1),
f(n) = min(k+1+f(n-2^k+2),k+1+2^(k+1)-1-n)

### 4. 错误与反思

- 可以迁移到其他题目的经验：
快速计算logn向下取整
```C++
int Log(i64 x)
{
    int res=0;
    for(int i=5;i>=0;i--)
        if(x>=(1LL<<(1<<i)))
        {
            x>>=(1<<i);
            res+=(1<<i);
        }
    return res;
}
```
