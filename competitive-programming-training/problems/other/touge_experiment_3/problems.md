# 三道算法题汇总

## 第一题：木乃伊地下宫殿

### 题目描述

木乃伊地下宫殿是一个 6 行 6 列的迷宫。游戏在木乃伊所在的迷宫里展开，你的任务就是尽快赶到出口。

你一次只能走一步，而木乃伊可以走两步。木乃伊总是优先尝试与你到达同一列；如果已经在同一列，它才会沿行的方向向你走来。有墙的地方，人和木乃伊都不能通过，你可以利用障碍物牵制木乃伊。

判断你是否能够安全到达出口。

### 输入格式

第一行输入墙的数量 `n`。

接下来 `n` 行，每行输入三个整数，分别表示格子的行、列和墙的位置：

- `0` 表示这个格子的下方是墙。
- `1` 表示这个格子的右方是墙。

再接下来三行，每行输入两个整数，依次表示木乃伊、人和出口的位置。

行、列编号均为 `0` 到 `5`。

### 输出格式

如果能够安全逃生，输出 `Yes`，否则输出 `No`。

答案占一行。

### 输入样例

```text
5
0 0 0
1 1 1
1 4 1
3 4 1
4 3 0
3 3
3 1
5 5
```

### 输出样例

```text
No
```

## 第二题：推箱子

### 题目描述

绝大多数人都玩过推箱子的游戏，控制一个人将箱子推动到目标位置即获得胜利。

请编写一个程序，判断将箱子推到目标位置至少需要多少步。

### 输入格式

推箱子的平面区域固定为 `10 × 10`，使用 10 行 10 列输入初始局面。

各数字含义如下：

| 数字 | 含义 |
| --- | --- |
| `0` | 空格 |
| `1` | 墙 |
| `2` | 箱子 |
| `3` | 目标位置 |
| `4` | 人 |

游戏中只有一个箱子、一个目标位置和一个人。

### 输出格式

输出将箱子推到目标位置的最小步数。

若箱子不可能被推到目标位置，输出 `-1`。

### 输入样例

```text
0000000000
0000000300
0100000000
0100000000
0101111100
0000010000
0000010000
0020010040
0000010000
0000010000
```

### 输出样例

```text
34
```

## 第三题：圆上点的最小总移动距离

### 题目描述

在一个周长为 `10000` 的圆上，等距分布着 `n` 个点，即这 `n` 个点是一个正 `n` 边形的顶点。

现在要另加 `m` 个点到圆上。新加的点可以任意选择位置，也可以与原有的点重合。

然后，将这 `n + m` 个点中的一些点沿圆周移动，最终使所有点均匀分布，即位于一个正 `n + m` 边形的顶点上。

求最小总移动距离。

### 输入格式

输入两个整数 `n`、`m`，满足：

- `2 ≤ n ≤ 1000`
- `1 ≤ m ≤ 1000`

### 输出格式

输出最小总移动距离，保留四位小数。

### 样例 1

输入：

```text
2 1
```

输出：

```text
1666.6667
```

### 样例 2

输入：

```text
2 3
```

输出：

```text
1000.0000
```

### 样例 3

输入：

```text
3 1
```

输出：

```text
1666.6667
```

### 样例 4

输入：

```text
10 10
```

输出：

```text
0.0000
```
